# CZM — утверждённый игровой UX лобби (23.10.2026)

## Правила
- Главное меню (утверждено 23.10): три **одинаковых по ширине, высоте и форме** кнопки строго вертикально друг под другом: **красная «Быстрая игра»**, **синяя «Создать лобби»**, **жёлтая «Поиск лобби»**. Одинаковые радиусы скруглений, аккуратные зазоры, одинаковая область касания. Без двух узких кнопок в одной строке.
- Каталог: только публичные комнаты, без вкладки приглашений; корректное пустое состояние с созданием комнаты.
- Приглашение: отдельная карточка поверх текущего меню с отправителем, названием, режимом/сервером, участниками и кнопками «Принять»/«Отклонить». Серверный TTL и блокировки обязательны. Системные уведомления при свёрнутом приложении потребуют отдельной надёжной доставки; не обещать пуши при остановленной игре без её внедрения.
- Комната: сверху выбранный сервер, слева 2–6 игроков (аватар, роль, готовность, говорящий), справа чат, снизу только «Готов», «В бой», «Сервер», «Друзья», «Выйти».
- Микрофон — реальная иконка, разрешение Android и ручное включение, зелёный маркер речи. Мут хозяина и локальный мут в контекстном меню; для хозяина отдельная маленькая иконка «мут всех».
- Стиль: графит/тонкие рамки/умеренный красный/зелёный для успешных статусов, без обрезанных кнопок. Проверять горизонтальные разрешения.
- Безопасность: разработка только в тестовой ветке, автотесты сервера/JNI и CI, полный APK c game-data. Google Play/проверенная бета и автоматическая публикация не трогаются.

## Этапы
1. Утвердить на уровне кода UX, убрать приглашения из каталога, переработать окно, иконки, карточки.
2. Сделать независимую доставку приглашений в открытом меню, серверную проверку и принятие/отклонение.
3. Отдельно системные push-уведомления Android при свёрнутой игре через надёжный канал доставки.
4. Проверить серверные тесты, компиляцию C++/JNI, полный Android CI, реальные скриншоты и работу с 2 телефонами.
