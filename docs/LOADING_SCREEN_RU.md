# Главное меню и экран загрузки

Утверждено владельцем 11 октября 2026 года.

## Что видит игрок

- **Главное меню:** арт владельца на весь экран, слева тёмный градиент под кнопки,
  сверху надпись Counter Zombie Mobile.
- **Экран загрузки** вместо консоли движка:
  - одна из 5 картинок владельца, каждый раз случайная;
  - название сервера, карта, игроки, пинг;
  - совет (10 вариантов, случайно);
  - этап загрузки, процент и полоса из 40 делений;
  - при скачивании — «файл N из M», мегабайты и скорость;
  - кнопка «Отмена» (и кнопка «Назад» телефона) — отключиться и вернуться в меню.
- Кнопки управления и консоль на время загрузки скрыты.
- Если подключиться не удалось, в меню появляется окно с причиной на русском.
- Консоль разработчика игрокам не показывается (запуск без `-dev`).

## Как устроено

| Часть | Где |
|---|---|
| Исходные картинки владельца | `assets/branding/menu-background.png`, `assets/branding/loading-1..5.png` |
| Текстуры игры | `3rdparty/czm_project/gfx/czm/` (создаёт `scripts/make_czm_art.py`) |
| Шрифты Inter (OFL) | `3rdparty/czm_project/gfx/fonts/czm/` |
| Рисование меню и загрузки | `czm/menu/CzmMenu.cpp` (подключается через `cmake/CzmBranding.cmake`) |
| Правки движка | `patches/xash3d-fwgs/0001-czm-loading-screen.patch` |

Движок считает прогресс и передаёт его меню через переменные `czm_loading*` и `scr_loading`.
Меню рисует экран. Подмодуль движка остаётся закреплённым: патч применяет
`scripts/apply_engine_patches.py` перед сборкой (повторный запуск безопасен).

Этапы и проценты:

| Этап | Проценты |
|---|---|
| Подключение | 2–8 |
| Данные сервера | 10 |
| Скачивание файлов сервера | 12–75, по байтам |
| Загрузка карты и моделей | 15–94 (75–94 после скачивания) |
| Вход в игру | 95–99 |

## Настройки для отладки

- `czm_loading_enable 0` — вернуть старый экран с консолью.
- `czm_loading_pump 0` — не перерисовывать экран во время загрузки карты.
- Файл `files/game/czm-dev.txt` в данных приложения — запуск с `-dev 2` и консолью.

## Замена картинок

Положить новые PNG в `assets/branding/` с теми же именами и запустить:

```sh
python3 scripts/make_czm_art.py
```
