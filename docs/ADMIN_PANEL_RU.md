# Админ-панель CZM

Панель управляет игроками, ролями и доступом к серверам через CZM. Она открывается из своего профиля кнопкой «Админ-панель», из Настройки → Профиль и кнопкой «Управлять» в карточке сервера. Обычным модераторам остаётся прежняя панель чата.

## Доступ

Нужны одновременно зарегистрированный аккаунт, существующая роль SUPPORT и публичный ID в серверной настройке `CZM_ADMIN_PLAYER_IDS`. По умолчанию список пуст. Пример формата настройки: `CZM_ADMIN_PLAYER_IDS=123`.

Разрешение проверяется на сервере при каждом запросе. Ник, почта в клиенте, значок или подменённая кнопка доступ не дают. Выдача Moderator, Tester или Server owner не расширяет этот список. Панель не выдаёт SUPPORT и не меняет список главных администраторов; эти операции остаются отдельными действиями владельца сервиса.

Настройка хранится в приватном окружении сервиса. Перед её изменением нужны проверка соответствия ID аккаунту владельца и приватная резервная копия. Не показывать значения остальных переменных окружения и не сохранять пароли в документации.

## Разделы

| Раздел | Возможности |
| --- | --- |
| Главная | Число аккаунтов, игроков за последние две минуты, жалоб, наказаний, ограниченных серверов и приостановленных модераторов; версии dev и Play |
| Игроки и роли | Поиск по нику, логину или ID; выдача и снятие Moderator, Official Tester CZM, Server owner; название проекта и удаление IP из профиля |
| Игрок | Причина и срок наказания, предупреждение, отключение текста/голоса, блокировка, сброс аватара, запрет своего фото, закрытие лобби; снятие действующих санкций |
| Серверы | Жалобы и ограничения, серверы проектов, открытие любого публичного IP:порт; общая блокировка и разбан с сохранением истории |
| Жалобы | Текст и контекст жалобы, текущее фото профиля при наличии, переход к игроку, предупреждение, удаление контента, наказание или отклонение |
| Модераторы | Счётчик 10 действий, период, баны за сутки и всё время, причины и история; пауза, возврат прав, отмена серии или всей истории |
| Наказания | Все активные санкции с постраничным просмотром и снятием |
| История | Отдельные страницы действий панели, модерации и назначения ролей, включая назначения через бота |

Роли можно назначать только зарегистрированным аккаунтам. Гостей можно модерировать, но нельзя сделать сотрудниками. Статус Server owner не превращает независимый игровой сервер в сервер CZM; панель ограничивает доступ через клиент CZM.

## Подтверждение и журнал

Выдача/снятие роли, блокировка, снятие наказания и другие изменения требуют подтверждения. При наказании и общей блокировке сервера причина обязательна. Для временных санкций есть 1 час, 1 день, 7 и 30 дней; бессрочный вариант доступен для блокировки и ограничения фото.

Новые действия панели записываются в `admin_actions`. Повтор сетевого запроса с тем же nonce и содержимым не повторяет операцию. Изменённое содержимое с прежним nonce отклоняется. Проверка доступа выполняется и перед возвратом сохранённого результата.

Наказания используют общую систему модерации: причины и действия доставляются главному администратору через служебного бота. Бот по-прежнему доступен только настроенным владельцам. Админ-панель не заменяет и не открывает бот обычным модераторам.

Перед отменой действий модератор приостанавливается, затем показывается свежая серия и число действий. Для полной отмены используется отпечаток последнего действия; изменившуюся историю нужно просмотреть заново. Более поздние решения других сотрудников сохраняются. После отмены права остаются приостановленными. Уже удалённые по сроку хранения данные не восстанавливаются.

Пароли, адреса почты, ключи входа и идентификаторы устройства в выдачу панели и её журнал не включаются. Удаление аккаунта не удаляет журнал действий безопасности.

## Щит проверенного проекта

Если аккаунт с назначенной администрацией ролью Server owner добавил публичный IP:порт в профиль, у сервера появляется щит. В списках он расположен между сердцем и звездой, в подробной карточке подписан «Проверенный» / «Verified». В списке и подробной карточке нажатие открывает профиль владельца. Щиты также показаны на главном экране, в лобби и карточках профилей.

Значок означает связь с владельцем проекта, которому назначена роль. Он не означает проверку Google, проверку всех файлов или гарантию доступности сервера. Удаление IP, отзыв роли, удаление аккаунта или общая блокировка сервера снимают отметку. Если адрес связан с несколькими владельцами, выбирается более раннее назначение роли, затем меньший публичный ID.

Данные приходят с отдельного публичного `/api/v1/servers/owners`, с `Cache-Control: no-store`. Это только адрес сервера и публичный ID владельца, уже доступные в профиле. Клиент обновляет их примерно раз в 15 секунд; после минуты без успешного обновления скрывает старую отметку. Собственные изменения в профиле и админке сбрасывают локальный кеш. Загрузка отметок не участвует в разрешении подключения к серверу.

## Выпуск и проверка

Код сервиса: `czm/admin.py`, роли и ассоциации: `czm/community.py`, интерфейс Android: `CzmAdmin.java`, кеш отметок: `ServerOwners.java`. Новые разрешения Android не требуются.

Перед выкладкой: серверные тесты в изолированной базе, CI Android, резервные копии SQLite и окружения, установка точного SHA, проверка доступа без ключа и по существующему разрешённому аккаунту. Не создавать реальные наказания ради проверки. Полный dev APK доставляется через существующий приватный канал. Google Play выпускается отдельным решением владельца.
