# Жалобы на игровые серверы

В карточке сервера есть «Заблокировать», в меню паузы — «Пожаловаться на сервер».
Нужен вход в аккаунт CZM с подтверждённой почтой. В окне «Заблокировать сервер» игрок отмечает одну или несколько причин галочками и при желании вписывает свою причину. Кнопка «ОК» отправляет жалобу и скрывает сервер у игрока.
Скриншоты, журналы, пароли и ключи входа автоматически не отправляются.

Одна подтверждённая почта может пожаловаться на один адрес и порт раз в **30 дней**. Правило
проверяет сервис; смена телефона, аккаунта с той же почтой, перезапуск игры или разбан сервера его не сбрасывают. Смена почты в том же аккаунте также не обходит действующий срок.
Повторная доставка одного запроса возвращает прежний результат без новой записи.
Исходный адрес почты в таблице жалоб не записывается и в бот не передаётся: для лимита используется защищённый хеш с серверным секретом, очищаемый после срока при плановой очистке.

Новые обращения после 30 дней увеличивают общий счётчик; число разных заявителей
показывается отдельно. Ограничение 20 новых обращений в минуту на аккаунт/устройство
дополнительно защищает от технической рассылки по множеству адресов.

После принятия жалобы сервер скрывается только у её автора. В списке серверов есть
«Заблокированные»: переключатель «Скрывать» включает/выключает личное скрытие,
«Убрать» удаляет запись. Жалоба, её счётчики и срок 30 дней при этом сохраняются.
Личный список принадлежит аккаунту, синхронизируется между его устройствами и
удаляется с аккаунтом; другой пользователь его не видит. Выключение переключателя
или удаление записи не отменяет общую блокировку CZM. Личная блокировка ограничивает
новые подключения; уже идущий матч не прерывает.

## Бот владельца

На каждую принятую жалобу бот присылает короткую карточку:

```text
Название сервера
IP:порт · Жалоб: 7 · Игроков: 4
От: Ник · ID 9
От автора: 12 жалоб · Серверов: 3
Причины: Нацизм / ненависть; Спам / обман
Своя причина: Пояснение игрока
```

ID — публичный номер аккаунта CZM. Почта, пароль и сессионный токен в карточку не входят.
Статистика автора охватывает все его сохранённые жалобы, в том числе на другие серверы.
Выбранные причины и собственное пояснение хранятся в служебной базе и включаются в компактную карточку Telegram.
При сбое доставки необработанная карточка остаётся в очереди для каждого владельца.

| Команда | Действие |
|---|---|
| `/server_reports` | Серверы с жалобами: название, адрес, счётчик и число разных заявителей; сверху больше жалоб |
| `/server_reports 2` | Следующая страница, по 25 серверов |
| `/server IP:порт` | Счётчик выбранного сервера и отметка блокировки |
| `/server_ban IP:порт причина` | Ограничить сервер в CZM до пересмотра |
| `/server_unban IP:порт` | Восстановить доступ |

Команды исполняются только для `CZM_BOT_OWNER_IDS` и только в личном диалоге с ботом.
API изменения блокировок для обычных игроков нет. Количество жалоб само по себе
не вызывает бан. Решение, причина и идентификатор модератора сохраняются в журнале.
Разбан сохраняет историю жалоб, счётчики и ограничение повторной подачи.

## Действие ограничения

Блокируется конкретный **IP и порт**, а не название или все серверы на одном IP.
Поддерживаются числовые IPv4/IPv6; команда не выполняет DNS-запросы по присланному имени.

Новая игра получает публичный список ограниченных адресов через HTTPS; там нет
личностей заявителей, жалоб, счётчиков и служебных причин. Список в памяти обновляется
примерно раз в 30 секунд, перед новым подключением запрашивается свежая версия.
Подтверждённая блокировка также завершает действующее подключение к этому серверу; ошибка фоновой проверки сама по себе не прерывает матч. Фавориты и закрепления сохраняются на диске и скрываются на время ограничения;
после разбана снова видны без ручного добавления.

Проверка в движке перед сетевыми пакетами охватывает оба протокола, ручной `connect`,
повторное подключение, выбор из поиска/истории, приглашения и запуск лобби.
Проверка HTTPS асинхронна и не блокирует кадры игры. Пока она идёт, сетевые попытки
не расходуются. При недоступности проверки новое онлайн-подключение отклоняется с
предложением проверить интернет и повторить; локальная игра не требует сервиса.

На сервисе отдельно запрещены создание/смена лобби, приглашения и запуск на
ограниченный сервер, включая блокировку во время проверки свободных мест.
Старые установленные версии без нового кода не получают защиту на уровне движка.
Внешний сервер вне CZM не выключается. Этот механизм не подтверждает права на ресурсы
APK и не заменяет проверку их лицензий.

Частные GET/POST `/api/v1/servers/hidden` требуют сессию аккаунта и всегда работают
только с его личным списком. POST `/api/v1/servers/report` возвращает обновлённый
личный список для немедленного скрытия; старый ответ другого аккаунта отбрасывается.

## Проверка

Серверные тесты проверяют срок до секунды, доставку одного запроса без повторного
подсчёта, статистику автора и разных заявителей, права владельца, очередь при сбое,
бан отдельного порта, разбан, лобби и удаление аккаунта без нарушения внешних ключей.
Нативный тест проверяет скрытие/возврат строк и доступность кнопки жалобы в разных
разрешениях. JVM-тест проверяет загрузку политики, свежесть, ошибки, гонку запросов,
IPv4/IPv6 и восстановление после разбана; отдельный тест исполняет общий guard движка.

Боевая приёмка Android нужна для формы, Telegram-доставки и перехода бан/разбан
между двумя обновлёнными устройствами. В Google Play версия публикуется отдельно.
