# Карточка игрока CZM

Широкая карточка одинакова по структуре для всех игроков: крупный настоящий аватар, ник, выданные роли и текущий тег топа, копирование ID, присутствие, место в рейтинге и время на серверах. Под ней — подпись, три плитки «Друзья / Подписчики / Подписки», дата регистрации и разрешённые действия. XP и уровни не добавляются.

## Оформление

В своём профиле кнопка «Фон» открывает четыре готовых варианта: огненный фронт, ледяной рубеж, заброшенный город и заражённая лаборатория. Выбор доступен каждому зарегистрированному игроку, сохраняется с аккаунтом и показывается другим. Отмена закрывает выбор без изменения фона; сохранение применяется после успешного ответа сервиса.

Иллюстрации находятся в `3rdparty/czm_project/gfx/czm/profile/`. Подписи и кнопки не впечатываются в картинку. Ник открывает настройки профиля, личная подпись редактируется нажатием строки или карандаша. Шестерёнка и доступ главного администратора сохраняются.

У карточки мягкое появление, подсветка аватара и рамки, семь медленно движущихся частиц. Эффекты не меняют данные, роли или доступ. Превью выбора фона не запускают частицы. Роли имеют свой цвет; SUPPORT и топ показываются независимо. Несколько ролей переносятся на следующие строки.

## Чужой профиль

Профиль из чата и из топа открывает одно и то же окно по публичному ID. Основная кнопка зависит от отношений:

| Состояние | Действие |
| --- | --- |
| Ещё не знакомы | Добавить в друзья |
| Исходящая заявка | Заявка отправлена; повтор не создаётся |
| Входящая заявка | Принять в друзья |
| Взаимные друзья | Написать |
| Игрок заблокирован | Разблокировать |

Личные сообщения остаются только между друзьями. У гостевого профиля есть пояснение, почему дружба недоступна. Присоединение и приглашение в лобби показываются по действующим правилам; проверка ограничений сервера сохраняется. Меню «Ещё» содержит жалобу, блокировку и прекращение дружбы/отзыв заявки.

У Server owner остаётся блок максимум пяти серверов. В обычных размерах он расположен ниже баннера справа. На низком экране используется компактная компоновка, чтобы список, кнопки и дата не выходили за границы. Отметки проверенного владельца и глобальные ограничения серверов не меняют смысл.

## Хранение и проверка доступа

Поле `social_profiles.theme` имеет значение `ember` по умолчанию; миграция добавляет его, сохраняя статус и присутствие. Ответ профиля включает тему. POST `/api/v1/social/theme` принимает только `ember`, `frost`, `city`, `lab` и изменяет только профиль текущего зарегистрированного аккаунта. Ссылки и пути файлов не принимаются; роли и показатели не меняются. На клиенте также есть список разрешённых тем и безопасный фон по умолчанию для старого ответа сервиса.

Код представления: `CzmProfileStyle.h` и `CzmSocial.cpp`; сервис: `social.py`, `api.py`, миграция `db.py`. Новых разрешений Android нет. Фоновые изображения входят в пакет клиента и проверяются внутри APK.

Серверные проверки охватывают видимость выбора другим игрокам, сохранение при изменении статуса, изоляцию аккаунтов, отказ гостю/без ключа и неизвестным темам, миграцию старого профиля. Native-проверки охватывают RU/EN, свои/чужие/гостевые карточки, все роли одновременно, рейтинг, пять серверов, варианты экранов, кнопки дружбы, контекст жалобы и сохранение темы. Отрисовка дополнительно проверяется по трассе команд native-меню. Проверка на реальном телефоне выполняется после установки dev APK.
