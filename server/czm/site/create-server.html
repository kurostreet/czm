02 / УСТАНОВКА

Распакуй. Настрой. Запусти.

На компьютере с Windows

  1. Скачай и полностью распакуй архив

    Правой кнопкой по ZIP → «Извлечь всё». В качестве места выбери C:\. Получится папка C:\CZM-Server-Windows. Не запускай файлы прямо из окна архива. Путь должен быть без пробелов и кириллицы.

  2. Открой 1-INSTALL.cmd

    Укажи название, UDP-порт, число мест и ботов. Для начала оставь порт 27015 и одного бота. Пароль входа можно оставить пустым. Администратор Windows для обычной установки не требуется.

    Установщик загрузит компоненты, поставит Zombie Plague и подготовит карту zm_czm_start. Не закрывай окно до сообщения «Готово». Журнал установки — logs\install.log.

  3. Открой 2-START.cmd

    Оставь окно сервера открытым. После запуска карты можно подключаться с телефона. Сам по себе сервер не появляется у всех игроков в общем списке: сначала добавь его вручную по IP и порту.

  4. Остановка и повторный запуск

    Для штатной остановки нажми Ctrl + C в окне сервера. 4-STOP.cmd — запасная кнопка аварийной остановки этого экземпляра. Для следующего запуска снова открой 2-START.cmd; повторная установка не нужна.

Что уже настроено

Zombie Plague 4.4, классы зомби, один бот, меню AMXX и стартовая карта. Предустановленных администраторов и общего служебного пароля нет. Доступ хозяина выдаётся отдельно по его ID.

На Linux-компьютере или VDS

  1. Подготовь систему

    Подключись к VDS по SSH. Эти команды выполняет администратор системы. Для работы 32-битного игрового процесса на x86-64 нужны библиотеки совместимости.

    sudo apt-get update
sudo apt-get install -y python3 ca-certificates curl libc6-i386 lib32gcc-s1 lib32stdc++6

    Создай отдельного обычного пользователя, если его ещё нет. Если уже работаешь под таким пользователем, этот шаг можно пропустить.

    sudo adduser czmserver

    Заверши создание пользователя, затем переключись на него:

    sudo -iu czmserver

  2. Скачай и распакуй комплект

    Следующие команды выполняй уже под обычным пользователем, в его домашней папке. Не распаковывай комплект поверх работающего сервера.

    curl -fL --retry 3 https://counter-zombie.ru/server-downloads/CZM-Server-Linux-v1.0.0.tar.gz -o CZM-Server-Linux-v1.0.0.tar.gz
tar -xzf CZM-Server-Linux-v1.0.0.tar.gz
cd CZM-Server-Linux
bash install.sh

  3. Укажи настройки и запусти

    Установщик спросит название, порт, число игроков и ботов. Оставь окно открытым, пока SteamCMD и мод устанавливаются. После сообщения «Готово»:

    bash start.sh

    Для остановки — Ctrl + C. При таком запуске сервер зависит от открытой SSH-сессии. Для постоянной работы используй службу ниже.

  4. Включи автозапуск на VDS

    После успешной установки в папке появится czm-zombie.service с твоим пользователем и путём. Убедись, что служба с таким именем ещё не используется другим сервером. Команды выполняет пользователь с правом sudo из папки комплекта.

    sudo install -m 644 czm-zombie.service /etc/systemd/system/czm-zombie.service
sudo systemctl daemon-reload
sudo systemctl enable --now czm-zombie
sudo systemctl status czm-zombie

    Созданный через adduser пользователь обычно не имеет sudo. Можно выйти из его SSH-сессии командой exit и выполнить команды выше из административного аккаунта, сначала перейдя в /home/czmserver/CZM-Server-Linux.

    Перезапуск:

    sudo systemctl restart czm-zombie

    Остановка:

    sudo systemctl stop czm-zombie

    Последние строки журнала:

    sudo journalctl -u czm-zombie -n 50

    Не запускай одновременно службу и start.sh с одним и тем же портом.

03 / ПРОВЕРКА

Зайди на свой сервер

  1. Найди правильный адрес

    Дома: подключи телефон и компьютер к одной Wi-Fi сети. В Windows команда ipconfig покажет IPv4 активного адаптера; на Linux используй hostname -I. Нужен адрес вроде 192.168.1.50.

    На VDS: используй публичный IPv4 из панели хостинга. Внутренний адрес вида 192.168.x.x не подходит для игроков из интернета.

  2. Добавь адрес в Counter Zombie Mobile

    Открой «Серверы → +», введи IP:порт, например 192.168.1.50:27015, и подключись. Если включён пароль входа, введи его.

  3. Проверь мод и бота

    Дождись загрузки карты и начала раунда. В стартовом комплекте один бот, чтобы можно было проверить заражение и бой без других игроков. Адрес 127.0.0.1 на телефоне указывает на сам телефон, а не на твой компьютер.

Прямое подключение по адресу не требует назначения роли Server owner. Значок проверенного владельца и публичное размещение сервера — отдельные действия администрации CZM.

04 / ДРУЗЬЯ

Открой доступ из интернета

Домашний компьютер

Закрепи локальный IP компьютера в роутере. Создай правило перенаправления UDP 27015 → IP компьютера:27015. Если выбрал другой порт, используй его везде.

Разреши этот UDP-порт в брандмауэре ОС. Для Windows команда ниже выполняется один раз в PowerShell от администратора и относится только к серверному файлу.

VDS

Разреши UDP-порт в сетевом экране ОС и в панели хостинга, если там есть отдельный firewall. Если используешь UFW:

sudo ufw allow 27015/udp

Не включай и не сбрасывай firewall вслепую: доступ по SSH должен сохраниться.

New-NetFirewallRule -DisplayName "CZM Server UDP 27015" -Direction Inbound -Action Allow -Protocol UDP -LocalPort 27015 -Program "C:\CZM-Server-Windows\game\hlds.exe"
Если у провайдера CGNAT: обычный проброс порта не даст вход из интернета. Нужен публичный IPv4 у провайдера или VDS. Проверяй внешний вход с телефона через мобильную сеть — домашний роутер может не поддерживать обращение к своему внешнему IP из той же Wi-Fi сети.

Игра использует UDP. Открытие адреса в браузере, TCP-сканер и Windows portproxy не проверяют и не перенаправляют игровой UDP.

05 / СКОРОСТЬ

Файлы должны скачиваться быстро

Игровой сервер и хранилище карт — разные соединения. Подготовь HTTPS FastDL перед тем, как приглашать игроков: без него крупные файлы могут передаваться через медленный игровой канал.

  1. Используй готовую папку fastdl

    Установка уже собрала туда карты, модели и звуки с нужной структурой. Конфиг сервера, плагины и пароли туда не включаются. На Windows загрузи содержимое этой папки на свой HTTPS-хостинг. Например, если файл лежит в fastdl/maps/zm_czm_start.bsp, его публичный адрес должен быть https://files.example.com/files/maps/zm_czm_start.bsp.

  2. Или настрой HTTPS на отдельном домене своей VDS

    В DNS направь A-запись files.ТВОЙ-ДОМЕН на публичный IP VDS. Для Caddy нужны входящие TCP 80 и 443. Команды ниже копируют только публичные ресурсы; выполняй их из папки установленного комплекта с правами администратора.

    sudo apt-get install -y caddy
sudo install -d -m 755 /var/www/czm-fastdl
sudo cp -a fastdl/. /var/www/czm-fastdl/
sudo chmod -R a+rX /var/www/czm-fastdl

    В /etc/caddy/Caddyfile добавь блок, заменив files.example.com своим настоящим доменом. Если там уже настроены сайты, сохрани существующие блоки.

    files.example.com {
    handle_path /files/* {
        root * /var/www/czm-fastdl
        file_server
    }
}
    sudo caddy validate --config /etc/caddy/Caddyfile && sudo systemctl reload caddy

  3. Укажи адрес хранилища серверу

    В server.ini задай свой адрес с завершающим слешем:

    fastdl_url = https://files.example.com/files/

    На Windows открой 3-SETTINGS.cmd; на Linux выполни bash configure.sh. Затем перезапусти игровой сервер.

  4. Проверь с телефона без VPN

    Открой полный URL карты в браузере телефона через мобильную сеть. Должен скачаться именно BSP-файл, а не HTML-страница входа или ошибка 404. После этого проверь вход через игру. Доступность чужих провайдеров и хостингов может отличаться.

  5. Обновляй ресурсы после добавления карт

    Снова подготовь экспорт и загрузи обновлённое содержимое на свой HTTPS-хостинг. При локальном Caddy повтори копирование в /var/www/czm-fastdl. На Linux:

    python3 installer.py export-fastdl

    На Windows — из папки комплекта:

    runtime\python.exe installer.py export-fastdl

Как выдать себе админку

Зайди в игру и введи status в консоли серверного окна. Найди свой уникальный ID вида STEAM_0:1:123456 или VALVE_0:1:123456. Останови сервер и выполни одну из команд из папки комплекта, подставив свой ID:

Linux:

python3 installer.py admin STEAM_0:1:123456

Windows:

runtime\python.exe installer.py admin STEAM_0:1:123456

После перезапуска открой консоль игры и введи amxmodmenu. Для службы VDS можно сначала запустить сервер вручную через start.sh, получить ID из его консоли и затем вернуться к службе. Не выдавай права общим идентификаторам вроде STEAM_ID_LAN.

Пароль входа в игру — не пароль администратора. RCON изначально выключен. Свою настроенную папку не публикуй целиком: распространяй исходный установочный архив, а для загрузки карт — только папку fastdl.

07 / ПОМОЩЬ

Если что-то не работает

Установщик не скачивает компонент

Проверь доступ к Steam и GitHub, свободное место и logs/install.log. Незавершённую установку можно повторить. При ошибке контрольной суммы не отключай проверку — скачай актуальный комплект с этой страницы.

«No such file», «не является приложением» или не хватает библиотеки

Убедись, что архив полностью распакован и выбран под нужную ОС. На Linux установи зависимости из первого шага. ARM не поддерживается этим комплектом. Linux-архивы Xash3D нельзя запускать двойным щелчком в Windows.

Сервер работает дома, но друзья не подключаются

Проверь UDP-порт в ОС и панели хостинга, IP назначения в роутере и наличие публичного IPv4. При CGNAT домашнего проброса недостаточно. Для внешнего теста используй мобильную сеть. Не выключай весь firewall.

Файлы висят или скачиваются по 20–30 КБ/с

Проверь FastDL по полному URL файла с проблемного устройства. Сервер может отвечать на игровой запрос, а файловый хостинг — быть недоступным или медленным. Настрой доступный HTTPS-источник; одна только замена игрового порта не исправляет файловую загрузку.

Порт занят или сервер запускается дважды

Останови предыдущий экземпляр. На VDS проверь systemctl status czm-zombie. Для двух серверов нужны отдельные папки и разные UDP-порты.

Как добавить сервер в профиль владельца CZM?

Сначала запусти сервер и проверь доступ по публичному IP. Затем обратись в сообщество CZM по вопросу роли Server owner. Роль выдаёт администрация; она позволяет перечислять адреса своего проекта в профиле, а не назначает игровую админку.
