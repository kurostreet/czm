CZM SERVER 1.0.0
Зомби-сервер для Counter Zombie Mobile
Полная инструкция: https://counter-zombie.ru/create-server

ЧТО ЭТО
Настроенный установочный комплект: ReHLDS, ReGameDLL, Metamod-R, AMX Mod X,
Reunion, Zombie Plague 4.4, YaPB и один бот для проверки. Игровой процесс —
32-битный; он работает и на 64-битных Intel/AMD компьютерах и VDS.
Для первого запуска нужны интернет и минимум 3 ГБ свободного места.
SteamCMD получает базовые игровые данные напрямую у Valve; остальные
компоненты загружаются из указанных в packages.json официальных источников.
Каждый архив проверяется по SHA-256. Пароли и удалённые администраторы
в комплект не включены. RCON изначально отключён.

WINDOWS 10/11 x64
1. Распакуйте ZIP полностью в C:\. Получится C:\CZM-Server-Windows.
   Не запускайте файлы из окна ZIP. В пути не должно быть пробелов и кириллицы.
2. Откройте 1-INSTALL.cmd. Укажите название, порт, число мест и ботов.
   Установка может занять несколько минут. Журнал: logs\install.log.
3. Откройте 2-START.cmd. Дождитесь запуска карты zm_czm_start.
4. На телефоне в той же Wi-Fi сети: Серверы → + → IPv4 компьютера:27015.
   IPv4 смотрите командой ipconfig. 127.0.0.1 на телефоне не подходит.
5. Остановка: Ctrl+C в окне сервера. 4-STOP.cmd — аварийная остановка
   только этого процесса. 3-SETTINGS.cmd открывает server.ini; после
   сохранения настройки проверяются. Затем перезапустите сервер.
6. Для внешних игроков разрешите UDP 27015 в брандмауэре Windows и
   пробросьте этот UDP-порт на роутере к локальному IP компьютера.
   При CGNAT запросите публичный IPv4 у провайдера или используйте VDS.
   TCP-проброс portproxy и проверка порта в браузере не проверяют игровой UDP.

LINUX / VDS (Debian 12, Ubuntu 22.04/24.04, Intel/AMD x86-64)
Администратор системы один раз устанавливает зависимости:
  sudo apt-get update
  sudo apt-get install -y python3 ca-certificates curl libc6-i386 lib32gcc-s1 lib32stdc++6
Создайте обычного пользователя (если ещё нет):
  sudo adduser czmserver
  sudo -iu czmserver
Скачайте и распакуйте комплект в домашней папке этого пользователя:
  tar -xzf CZM-Server-Linux-v1.0.0.tar.gz
  cd CZM-Server-Linux
  bash install.sh
  bash start.sh
Устанавливать и запускать игру от root не нужно. Для остановки — Ctrl+C.
Настройки: nano server.ini, затем bash configure.sh и перезапуск.
В сетевом экране VDS и, при наличии, firewall хостера откройте UDP 27015.
Установщик не меняет правила firewall, SSH или существующие веб-сайты.

АВТОЗАПУСК LINUX
После успешной установки создан czm-zombie.service для текущего пользователя
и точного пути. Убедитесь, что это нужная папка; если файл службы с таким именем
уже существует, сначала проверьте его и сохраните копию.
  sudo install -m 644 czm-zombie.service /etc/systemd/system/czm-zombie.service
  sudo systemctl daemon-reload
  sudo systemctl enable --now czm-zombie
  sudo systemctl status czm-zombie
Остановка: sudo systemctl stop czm-zombie
Перезапуск: sudo systemctl restart czm-zombie
Журнал: sudo journalctl -u czm-zombie -n 50
При служебном запуске не запускайте второй экземпляр через start.sh.

БЫСТРАЯ ЗАГРУЗКА (FASTDL)
Установка готовит fastdl/ с картами, моделями и звуками, без server.cfg,
паролей и плагинов. Разместите содержимое этой папки на своём HTTPS-хостинге,
сохранив вложенные папки. Пример: https://files.example.com/files/.
В server.ini укажите этот адрес в fastdl_url, затем примените configure
и перезапустите игру. Для новой карты/моделей снова запустите:
  python3 installer.py export-fastdl
В Windows:
  runtime\python.exe installer.py export-fastdl
Проверьте прямую загрузку maps/zm_czm_start.bsp по вашему URL с телефона
через мобильную сеть без VPN. Успех подключения к игровому UDP не гарантирует
доступность отдельного HTTPS-хостинга. С пустым fastdl_url остаётся медленная
передача файлов через игру — это подходит для первого локального теста.

АДМИНИСТРАТОР
В серверной консоли status покажет уникальный STEAM_x:x:число или
VALVE_x:x:число игрока. После остановки сервера выполните:
  python3 installer.py admin STEAM_0:1:123456
или в Windows:
  runtime\python.exe installer.py admin STEAM_0:1:123456
Замените пример своим настоящим ID. После перезапуска в игровой консоли
введите amxmodmenu. Встроенных администраторов в сборке нет.
Не публикуйте свою настроенную папку целиком: в ней есть личные конфиги.

ЕСЛИ НЕ ПОЛУЧИЛОСЬ
Ошибка установки: смотрите logs/install.log; повторный install продолжит
незавершённую установку. Уже установленную игру install не переустанавливает.
Не скачивается компонент: проверьте доступ к GitHub и Steam. Проверку хешей
не отключайте; при изменении архива используйте обновлённый комплект.
Сервер не виден извне: проверьте UDP, firewall хостера, роутер и CGNAT.
Порт занят: остановите первый экземпляр или выберите другой в server.ini.
Медленно качаются файлы: проверьте HTTPS FastDL и прямой URL конкретного файла.
Это стартовая конфигурация, а не гарантия работы любого стороннего мода.
