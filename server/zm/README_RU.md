# Сервер Survival (перенос Kontra на CS 1.6)

Тестовый сервер: `194.226.112.249:27016` (`czm-zm-test.service`, `/srv/czm-zm-test/game`).
Движок: ReHLDS + ReGameDLL + Metamod + AMX Mod X 1.10 + Zombie Plague 4.3 + ReAPI + AmxxEasyHttp.

По решению владельца не переносим: PropsManager, Strafes, дуэли, мини-карту (в CS есть свой радар).

Скины Gsg9 admin, Sas custom, Leet pirate, Professional и Survivor — свои модели
`models/player/czm_*` (откуда — в `CREDITS.md`); остальные скины — стоковые модели CS.
Если своей модели на сервере нет, игрок получает стоковую из поля `base` каталога.

Картинки скинов и ножей в панели рисует `tools/render_models.py` из этих же моделей (поза и
оружие как в игре, ножи — как их видит игрок) при установке контента: `/zm-test-files/czm-art/`.
Пока картинки нет, панель показывает прежнюю из `site/assets/lvl/`.

## Меню сервера и новые плагины

`czm_menu.amxx` загружается перед плагинами, которые подключают `<czm_menu>`. Команда `/menu`
открывает общее окно CZM; обычные клиенты получают текстовое меню с теми же действиями.
Заголовок `#czm1` и разделители табуляции — протокол, их нельзя пропускать через переводчик
`titles.txt` или обрезать до 1024 байт. Клиент собирает все фрагменты `ShowMenu`, затем разбирает окно.

Плагин регистрирует вкладку и карточки в `plugin_init`. Изменять код главного меню или выпускать
APK для каждой новой вкладки не требуется:

```pawn
#include <amxmodx>
#include <czm_menu>

public plugin_init()
{
    register_plugin("Server statistics", "1.0", "kurostreet");
    czm_menu_section("extra_stats", "Статистика", "Statistics", "chart", 45);
    czm_menu_item("extra_stats", "extra_stats_open", "Мои результаты", "My results",
        "Данные этого сервера", "This server's data", "chart", "6BDAA7", "on_stats");
    czm_menu_item("main", "go_extra_stats", "Статистика", "Statistics",
        "", "", "chart", "", "#extra_stats", 45);
}

public on_stats(id, const key[])
{
    // Здесь плагин выполняет своё действие для id.
}

public czm_menu_build(id, const section[])
{
    if (equal(section, "extra_stats"))
        czm_menu_state(id, "extra_stats_open", "", "", "NEW");
}
```

Ключи вкладок и карточек должны быть уникальными для всех плагинов. Ключ раздела — до 15
латинских букв, цифр или `_`, карточки — до 23. Другой плагин не может перезаписать занятый ключ.
`order` задаёт порядок; меньшие числа идут раньше. `czm_menu_state` меняет подпись/метку,
скрывает или отключает карточку только на время построения меню конкретного игрока.
Обработчик `#имя_вкладки` открывает вкладку, обычное имя — `public`-функцию плагина.
Выключенный в конфигурации плагин после перезапуска не регистрирует свои пункты.

В окне находятся только команды сервера и связанная панель на сайте. Настройки управления,
графики, HUD и звука находятся в настройках игры. VIP+, PREMIUM, DELUXE, «Модератор» и «Админ» —
отдельные разделы: сервер отправляет только доступные текущему игроку.

| Флаг доступа | Кто видит и выполняет команду |
|---|---|
| `CZM_MENU_ALL` | Все игроки |
| `CZM_MENU_VIP` | Активный VIP+ |
| `CZM_MENU_PREMIUM` | Активный PREMIUM |
| `CZM_MENU_DELUXE` | Активный DELUXE |
| `CZM_MENU_TESTER` | Активный TESTER |
| `CZM_MENU_MODERATOR` / `CZM_MENU_STAFF` | Модератор и администратор |
| `CZM_MENU_ADMIN` / `CZM_MENU_HEAD` | Администратор |
| `CZM_MENU_PRIV` | Любая активная привилегия или сотрудник (совместимость) |

Флаги можно объединить через `|`, чтобы разрешить любую из перечисленных ролей.
Платные привилегии сопоставляются с фактическим видом привилегии; PREMIUM не означает VIP+.
Права сотрудника проверяются отдельно. Просроченная привилегия не даёт доступа.
Проверка на сервере выполняется при открытии раздела и повторно при выборе команды.

Готовый компилируемый шаблон: [`templates/czm_menu_plugin.sma`](templates/czm_menu_plugin.sma).
Он содержит корневую вкладку, ссылку с главной, подраздел, обработчик и динамическую метку.
Файл вне `scripting/`, поэтому сам по себе не устанавливает лишние пункты.
Подраздел задаётся последним аргументом `parent`:

```pawn
czm_menu_section("extra_details", "Подраздел", "Subsection", "users", 10, CZM_MENU_ALL, "extra_stats");
czm_menu_item("extra_stats", "extra_details_link", "Подробнее", "Details",
    "", "", "users", "63A1EF", "#extra_details");
```

Подраздел не занимает место в боковой панели; кнопка «Назад» возвращает к непосредственному
родителю. Доступ ко всем родителям обязателен, даже если подраздел помечен `ALL`.
Неизвестные родители и циклы не открываются. До 32 разделов и 192 карточек; длинные списки
получают страницы, а боковая панель при необходимости прокручивается.
Обычные окна выбора игрока, срока и категорий магазина на наших серверах используют тот же
стиль; меню выбора оружия сохраняет колесо или сетку.

Иконки берутся из `gfx/czm/ui/icon_<имя>.png`, затем `gfx/czm/menu/<имя>.png`, иначе используется
звезда. Собственная иконка должна раздаваться сервером вместе с ресурсами; имя содержит только
строчные латинские буквы, цифры и `_`.

## Теги LVL MOD и личный HUD

`CzmTag` передаёт уровень, WR, префикс с цветом и привилегию для TAB, прицела и чата.
`CzmToast` показывает награду токенами или новый уровень. Личный баланс в общие теги не входит.

Новая игра объявляет `czm_progress_ui 1`; только после проверки этой возможности `czm_lvl`
отправляет владельцу `CzmProgress`: шесть 32-битных чисел — уровень, токены, оставшиеся убийства,
шаг убийств, оставшееся время и шаг времени. Отрицательный уровень скрывает блок.
Данные и правила берутся из ответа API, обновления отправляются при изменении состояния.
Прогресс соответствует более заполненному из двух путей к следующему уровню; под полоской
указаны оставшиеся убийства и время. Старые клиенты новых сообщений не получают.

В редакторе HUD блок называется «Уровень и токены» / «Level and tokens». Его положение,
масштаб, прозрачность и видимость хранятся в `czm_hud_progress_{x,y,scale,opacity,hidden}`
и входят в сохранение настроек аккаунта и общую раскладку. На серверах без данных LVL блок скрыт.
В колесе оружия клиент показывает 3D-модель из текущего `player info`, включая скин,
назначенный сервером; настройка модели профиля не подменяет надетый скин.

Кнопка «Выйти с наблюдателей» отправляет обычный `jointeam 5`, как кнопка «Играть» при входе.
Она видна только команде наблюдателей, скрыта в меню и демозаписях и не меняет правила возрождения.
Подсказки с адресом панели, `/sound_off`, `/rus`, `/eng` остаются в одном месте — HUD `czm_info`;
его можно отключить через `/info_off`. Приветствие в чате их больше не повторяет.

## Профиль игрока

Игра перед подключением к нашему серверу берёт у API билет (`/api/v1/game/ticket`) и кладёт его в
`setinfo _czm`; через минуту убирает. `czm_core` проверяет подпись ключом
`/etc/czm/game-ticket.key` и адресом сервера (`czm_public_address`). Без билета игрок — гость:
звуки и меню есть, LVL MOD нет.

## Экономика

Все числа — в API (`survival.py`), игровой сервер только сообщает события и показывает ответ.
У каждого сервера своя экономика, как на Kontra: режим задаёт `czm_server_name` в server.cfg —
`survival` (ZM) или `escape` (ZE); плагины добавляют его к каждому запросу (`?mode=`), а панель
игрока переключает серверы вверху страницы. Профиль, вход, промокоды, баны и новости — общие.
Второй сервер (Escape) — те же плагины с `czm_server_name "escape"` и своим `czm_public_address`;
адрес вписывается в слот Escape в админ-настройках игры, и он сразу появляется в игре и в панели.

- раз в 10 секунд пачка (`/survival/server/report`): время, убийства, раунды; пачка повторяется
  с тем же номером, пока API не ответит, — дважды не засчитывается;
- покупки из меню игры и с сайта идут одной функцией `survival.action` с номером операции;
- сервер подписывается заголовком `X-CZM-Server` = sha256(ключ билетов + `|server`).

Промокоды создаёт владелец в боте: `/promo free50k tokens 50000`, `/promo free20lvl lvl 20`,
`/promo del код`, `/promo` — список. Игроки вводят `/promo КОД` в игре или на сайте.

## Установка

С телефона: `~/.czm-zm.sh <commit> check|install|content`
(`content` ещё раз ставит карты, звуки и модели из `/var/lib/czm/survival-src`).
`deploy/install.sh` сначала собирает все плагины, при ошибке ничего не меняет; конфиги
дописываются блоками между `// >>> CZM Survival` и `// <<< CZM Survival`; копия прежних
конфигов и плагинов — `/var/backups/czm-zm/before-*.tgz`.

Карты Kontra и звуки — данные владельца, лежат только на сервере (`/var/lib/czm/survival-src`),
в репозиторий не попадают. Сторонние файлы перечислены в `CREDITS.md`.
